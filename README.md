# Coffee Sales Analysis Project

## Project Overview

**Project Title**: Coffee Sales Analysis\
**Tools Used**: Microsoft Excel, Power Query

This project presents a comprehensive Coffee Sales Analysis Dashboard built using Microsoft Excel. The analysis focuses on uncovering key sales insights across various dimensions, such as sales trends, customer contributions, and regional performance. The dashboard serves as an interactive tool for data visualization and decision-making, showcasing advanced Excel features like XLOOKUP, INDEX-MATCH, Pivot Tables, and slicers.

![dashboard](https://github.com/Mohitjonwaal/Coffee_Sales_Project/blob/main/Screenshot%202025-01-07%20201618.png)
---

## Objectives

1. **Total Sales Overview**: Analyze sales data by coffee type (Arabica, Robusta, Excelsa, Liberica) across different time periods.
2. **Monthly and Daily Sales**: Examine trends to identify peak sales periods.
3. **Country-wise Analysis**: Understand sales performance in the United States, Ireland, and the United Kingdom.
4. **Top Customers**: Highlight the highest revenue-generating customers.

---

## Tasks Performed

1. **Data Cleaning**:

   - Removed duplicates and handled missing values.
   - Standardized data formats for consistency.

2. **Data Filling**:

   - Used **XLOOKUP** and **INDEX-MATCH** to fill missing values and link related information efficiently.

3. **Data Analysis with Pivot Tables**:

   - Summarized sales data by:
     - Coffee type
     - Country
     - Monthly and daily timeframes

4. **Visualization**:

   - Created dynamic visualizations using:
     - **Trend Lines**: For monthly and daily sales trends.
     - **Pie Charts**: To visualize sales distribution across coffee types.
     - **Bar Charts**: To display country-wise sales and top-performing customers.

5. **Advanced Analysis**:

   - Integrated slicers and timelines to enable interactive data filtering by time period, country, and coffee type.
